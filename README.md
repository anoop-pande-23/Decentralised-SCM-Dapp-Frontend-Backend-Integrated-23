# Decentralized Supply chain management Dapp
Decentralized Blockchain-Based Supply Chain Management DApp. Backend in Node.js/Express with Solidity smart contract integration. Features: product CRUD with RBAC, on-chain event tracking, product history, and JWT auth. Enables transparent, immutable, and secure supply chain management.

# Sample Hardhat Project

This project demonstrates a basic Hardhat use case. It comes with a sample contract, a test for that contract, and a Hardhat Ignition module that deploys that contract.

Try running some of the following tasks:

```shell
npx hardhat help
npx hardhat test
REPORT_GAS=true npx hardhat test
npx hardhat node
npx hardhat ignition deploy ./ignition/modules/Lock.js
```
